# AI 모델 테스트 프레임워크

> **警告 Warning**: 尚未完成正在优化前端随后重构后端及文件结构

대규모 언어 모델(LLM)의 구조화된 데이터 형식 파싱 능력을 평가하기 위한 자동화된 테스트 프레임워크입니다.

## 개요

이 프로젝트는 AI 모델의 다양한 구조화된 데이터 형식 파일 이해 및 분석 능력을 평가하고 테스트하기 위해 설계되었습니다. 사전 설정된 테스트 케이스를 통해 AI API를 자동으로 호출하고 반환된 결과를 예상 답변과 비교함으로써 모델의 형식 이해 성능을 정량적으로 측정합니다.

## 프로젝트 구조

```
초안A/
├── 테스트 소프트웨어/    # 메인 애플리케이션(Flask 백엔드 + HTML 프론트엔드)
├── 테스트 소프트웨어2/  # 구성 변형(다른 모델/매개변수)
├── 테스트 소프트웨어3/
├── 테스트 소프트웨어4/
├── 테스트 세트/       # 테스트 데이터 세트(실제 사案例 아님, AI 생성)
│   ├── 테스트될 파일/  # 다양한 형식의 샘플 파일
│   │   ├── XML/
│   │   ├── JSON/
│   │   ├── YAML/
│   │   ├── Markdown/
│   │   ├── DSL/
│   │   └──列表示例/
│   ├── 교육 비디오 테스트 문제/
│   ├── 실행 로그 테스트 문제/
│   ├── 기업 정보 테스트 문제/
│   └── UI.json       # 테스트 인터페이스 구성
├── 백업/             # históricas 형식 백업
├── 업데이트 로그/    # 버그 수정 로그
└── 작업 설명/        # 개발 작업 문서
```

## 지원되는 형식

- XML
- JSON
- YAML
- Markdown(테이블, KV 키-값 쌍 포함)
- DSL(도메인 특정 언어)
- 일반 텍스트 목록

## 핵심 기능

1. **다중 형식 테스트**: 여러 데이터 형식의 파싱能力を 동시에 테스트
2. **배치 테스트**: 스트리밍 출력으로 테스트 케이스를 배치로 실행
3. **다중 모델 지원**: 비교 테스트를 위해 여러 AI 모델 구성
4. **답변 캐싱**: 반복적인 API 호출을 피하고 반복 테스트 가속화
5. **사용자 정의 시스템 프롬프트**: bindings.json을 통해 테스트 연관 구성
6. **동시성 제어**: 구성 가능한 동시성 및 재시도 횟수

## 빠른 시작

### 1. 종속성 설치

```bash
pip install -r 테스트 소프트웨어/requirements.txt
```

### 2. 서비스 시작

```bash
cd 테스트 소프트웨어
python app.py
# 또는 run.bat 더블 클릭
```

### 3. 인터페이스 액세스

브라우저에서 http://localhost:5000 열기

### 4. 구성 및 실행

1. 설정에서 API 주소 및 모델 매개변수 구성
2. 테스트할 형식 파일 및 테스트 문제 그룹 선택
3. "테스트 시작" 클릭
4. 실시간 결과 스트림 및 최종 점수 보기

## 구성

| 매개변수 | 설명 | 기본값 |
|------|------|--------|
| base_url | API 주소 | http://192.168.1.45:1919/v1 |
| model | 모델 이름 | qwen3.5-0.8b |
| temperature | 온도 | 0.7 |
| concurrency | 동시성 | 1 |
| test_count | 문제당 테스트 횟수 | 1 |
| max_retries | 최대 재시도 횟수 | 3 |

## API 엔드포인트

| 엔드포인트 | 메소드 | 설명 |
|------|------|------|
| /api/v1/config | GET/POST | 구성 관리 |
| /api/v1/models | GET | 사용 가능한 모델 가져오기 |
| /api/v1/ui-config | GET | 테스트 인터페이스 구성 가져오기 |
| /api/v1/question-groups | GET | 문제 그룹 가져오기 |
| /api/v1/bindings | GET/POST | 바인딩 구성 |
| /api/v1/run-tests | POST | 테스트 실행(SSE 스트리밍) |
| /api/v1/results | GET | 모든 테스트 결과 가져오기 |
| /api/v1/answer-cache | GET | 답변 캐시 가져오기 |

## 중요 공지

### 테스트 데이터 세트 선언

**이 프로젝트의 테스트 데이터 세트에 있는 모든 콘텐츠는 AI가 생성한 예이며 실제 사례 데이터가 아닙니다.**

테스트 세트에 다음이 포함됩니다:
- 교육 비디오 정보 예시
- 실행 로그 예시
- 기업 정보 예시
- 다양한 형식(XML, JSON, YAML, Markdown, DSL)의 샘플 파일

이 데이터는 구조화된 형식에 대한 AI 모델의 이해 및 분석 능력을 테스트하기 위한 것이며 실제 비즈니스 시나리오를 나타내지 않습니다.

## 기술 스택

- **백엔드**: Python Flask + Flask-CORS
- **프론트엔드**: Vanilla HTML + CSS + JavaScript
- **API 호출**: requests(스트리밍 SSE)
- **테스트 실행**: ThreadPoolExecutor 동시성
