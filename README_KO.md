# FormTest - AI 구조화 형식 파싱 평가 프레임워크

> **모든 테스트 데이터 세트는 AI가 생성한 가상 데이터이며 실제 데이터가 아닙니다. 실제 존재와의 유사성은 순전히 우연입니다.**
>
> **이 프로젝트는 프로그램 구축 및 테스트 계획이 충분히 수립되지 않았습니다. 코드 구조와 테스트 커버리지가 완전하지 않습니다. 참조 및 학습 목적으로만 사용하십시오.**

대규모 언어 모델(LLM)의 구조화된 데이터 형식 이해 및 파싱 능력을 평가하기 위한 자동화된 테스트 프레임워크입니다.

## 프로젝트 구조

```
FormTest/
├── 测试软件/              # 메인 애플리케이션(Flask 백엔드 + HTML 프론트엔드)
│   ├── app.py            # Flask 진입점, REST API + SSE 스트리밍
│   ├── config.json       # 런타임 설정
│   ├── requirements.txt  # Python 의존성
│   ├── run.bat           # 빠른 시작 스크립트
│   ├── static/           # 프론트엔드 파일
│   └── data/             # 런타임 데이터
├── 测试集/               # 테스트 데이터세트(AI 생성, 실제 데이터 아님)
│   ├── 教学视频测试/     # 교육 비디오 콘텐츠 테스트
│   ├── 企业信息测试/     # 기업 정보 테스트
│   ├── 运行日志测试/     # 시스템 운영 로그 테스트
│   └── Python进阶测试/   # Python 고급 지식 테스트
├── .gitignore
├── LICENSE               # Apache License 2.0
└── README*.md            # 다국어 README 파일
```

## 주요 기능

- **다중 형식 비교** — 동일 콘텐츠를 8가지 형식으로
- **배치 자동화** — 프롬프트 × 질문 × 모델의 데카르트 곱
- **다중 모델 병렬** — 여러 AI 모델 수평 비교
- **실시간 SSE 스트리밍**
- **다중 테스트** — 질문당 반복 실행 가능
- **동시성 제어**
- **증분 저장**
- **아카이브 스냅샷**

## 빠른 시작

```bash
pip install -r 测试软件/requirements.txt
cd 测试软件
python app.py
```

브라우저 열기: http://localhost:5000
