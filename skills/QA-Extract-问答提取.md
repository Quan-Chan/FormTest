# FormTest Q&A 提取 — 从源文件生成测试集

## 任务

从用户提供的源文件（文本、PDF、Markdown 等）中提取 **问题-答案对**，并输出为两个 JSON 文件，格式必须与 FormTest 测试集兼容。

---

## 输出文件 1：`测试问题/基础问题.json`

数组格式，每项一个问答对：

```json
[
  {
    "id": 1,
    "tag": "主题标签，如 Python进阶",
    "question": "问题文本",
    "answer": "答案文本（详尽、准确）"
  }
]
```

### 格式约定

- `id`：从 1 开始递增
- `tag`：统一标识主题，同一批所有问答共享同一个 tag
- `question`：完整独立成句，不需要额外上下文即可理解
- `answer`：包含足够细节；涉及代码用反引号 \`code\` 包裹，代码块用三个反引号

---

## 输出文件 2：`测试系统提示词/主题-格式名.json`

数组含一个对象：

```json
[
  {
    "id": 1,
    "tag": "格式名（如 原版、JSON、Markdown、DSL、YAML、XML、MarkdownKV、列表 等）",
    "default_questions": [
      "测试问题/基础问题.json"
    ],
    "content": "将源文件内容中的知识点提取整理成一篇完整的教学或参考材料文本"
  }
]
```

### 说明

- `content` 是 **提取并重组的知识正文**，而非逐条问答。它作为 AI 测试时的 system prompt 使用，应包含完整的知识体系（章节/分类结构、关键概念、要点解释），用自然段落或结构化格式（JSON/YAML/Markdown/DSL 等）呈现
- 与 `测试问题/` 中的问答互为补充：前者是知识体系，后者是评测问答

---

## 目录结构

每个子目录内需包含 `.test-set-part` 标记文件，内容标明类型。目录名可任意，系统通过标记文件识别。

```
<测试集名>/
├── <任意目录名>/
│   ├── .test-set-part      ← 内容: questions
│   └── 基础问题.json
└── <任意目录名>/
    ├── .test-set-part      ← 内容: prompts
    └── <主题-格式>.json
```

其中 `<测试集名>` 通常与源文件主题一致。

---

## 提取规则

1. **忠实于源文件**：不要编造源文件中不存在的信息
2. **问答覆盖全面**：确保所有关键知识点都有对应问答
3. **答案详细**：不少于 1-2 句话，必要时包含代码示例
4. **不添加外部知识**：不可掺杂源文件未提及的内容
