# AI मॉडल टेस्टिंग फ्रेमवर्क

संरचित डेटा प्रारूपों को समझने और पार्स करने की क्षमता का मूल्यांकन करने के लिए एक स्वचालित परीक्षण फ्रेमवर्क।

## अवलोकन

इस प्रोजेक्ट का उद्देश्य AI मॉडल की विभिन्न संरचित डेटा प्रारूप फ़ाइलों को समझने और पार्स करने की क्षमता का मूल्यांकन और परीक्षण करना है। पूर्व-निर्धारित परीक्षण मामलों के माध्यम से, यह स्वचालित रूप से AI API को कॉल करता है और परिणामों की तुलना अपेक्षित उत्तरों से करता है, जिससे प्रारूप समझ के प्रदर्शन को मात्रात्मक रूप से मापा जा सके।

## प्रोजेक्ट संरचना

```

├── टेस्ट सॉफ्टवेयर2/     # कॉन्फ़िगरेशन वेरिएंट (विभिन्न मॉडल/पैरामीटर)
├── टेस्ट सॉफ्टवेयर3/
├── टेस्ट सॉफ्टवेयर4/

│   ├── परीक्षण फ़ाइलें/    # विभिन्न प्रारूपों में उदाहरण फ़ाइलें
│   │   ├── XML/
│   │   ├── JSON/
│   │   ├── YAML/
│   │   ├── Markdown/
│   │   ├── DSL/
│   │   └── सूची उदाहरण/
│   ├── शिक्षा वीडियो परीक्षण प्रश्न/
│   ├── संचालन लॉग परीक्षण प्रश्न/
│   ├── उद्यम जानकारी परीक्षण प्रश्न/
│   └── UI.json           # परीक्षण इंटरफ़ेस कॉन्फ़िगरेशन
├── बैकअप/              # ऐतिहासिक प्रारूप बैकअप

└── कार्य विवरण/         # विकास कार्य दस्तावेज़
```

## समर्थित प्रारूप

- XML
- JSON

- Markdown (सारणियों, KV कुंजी-मान जोड़े सहित)
- DSL (डोमेन-विशिष्ट भाषा)
- सादा पाठ सूचियाँ

## मुख्य विशेषताएँ

1. **मल्टी-फॉर्मेट परीक्षण**: एक साथ कई डेटा प्रारूपों की पार्सिंग क्षमता का परीक्षण
2. **बैच परीक्षण**: स्ट्रीमिंग आउटपुट के साथ परीक्षण मामलों को बैच में निष्पा��ित करें
3. **मल्टी-मॉडल सपोर्ट**: तुलनात्मक परीक्षण के लिए कई AI मॉडल कॉन्फ़िगर करें
4. **उत्तर कैशिंग**: पुनरावृत्त परीक्षण को गति देने के लिए दोहराए जाने वाले API कॉल से बचें
5. **कस्टम सिस्टम प्रॉम्प्ट**: bindings.json के माध्यम से परीक्षण एसोसिएशन कॉन्फ़िगर करें
6. **समकालिकता नियंत्रण**: कॉन्फ़िगर योग्य समकालिकता और पुनः प्रयास गणना

## त्वरित प्रारंभ

### 1. निर्भरताएँ स्थापित करें

```bash
pip install -r टेस्ट सॉफ्टवेयर/requirements.txt
```

### 2. सेवा प्रारंभ करें

```bash
cd टेस्ट सॉफ्टवेयर
python app.py
# या run.bat पर डबल क्लिक करें
```

### 3. इंटरफ़ेस एक्सेस करें

ब्राउज़र में http://localhost:5000 खोलें

### 4. कॉन्फ़िगर और चलाएँ

1. सेटिंग्स में API पता और मॉडल पैरामीटर कॉन्फ़िगर करें
2. परीक्षण करने के लिए प्रारूप फ़ाइलें और परीक्षण प्रश्न समूह चुनें
3. "परीक्षण प्रारंभ करें" पर क्लिक करें
4. वास्तविक समय परिणाम स्ट्रीम और अंतिम स्कोर देखें
