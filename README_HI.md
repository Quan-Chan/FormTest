# FormTest - AI संरचित प्रारूप पार्सिंग मूल्यांकन ढांचा

> **सभी परीक्षण डेटा सेट AI-जनित काल्पनिक डेटा हैं, वास्तविक डेटा नहीं। किसी भी वास्तविक इकाई से समानता पूरी तरह से आकस्मिक है।**
>
> **इस परियोजना में प्रोग्राम निर्माण और परीक्षण की पर्याप्त योजना नहीं है। कोड संरचना और परीक्षण कवरेज अभी पूर्ण नहीं हैं। केवल संदर्भ और सीखने के उद्देश्यों के लिए।**

बड़े भाषा मॉडल (LLM) की संरचित डेटा प्रारूपों को समझने और पार्स करने की क्षमता का मूल्यांकन करने के लिए एक स्वचालित परीक्षण ढांचा।

## परियोजना संरचना

```
FormTest/
├── APPs/              # मुख्य एप्लिकेशन (Flask बैकएंड + HTML फ्रंटएंड)
│   ├── app.py            # Flask प्रवेश बिंदु, REST API + SSE स्ट्रीमिंग
│   ├── config.json       # रनटाइम कॉन्फ़िगरेशन
│   ├── requirements.txt  # Python निर्भरताएँ
│   ├── run.bat           # त्वरित प्रारंभ स्क्रिप्ट
│   ├── static/           # फ्रंटएंड फ़ाइलें
│   └── data/             # रनटाइम डेटा
├── Benches/               # परीक्षण डेटासेट (AI-जनित, वास्तविक नहीं)
│   ├── 教学视频测试/     # शिक्षण वीडियो सामग्री परीक्षण
│   ├── 企业信息测试/     # उद्यम जानकारी परीक्षण
│   ├── 运行日志测试/     # सिस्टम संचालन लॉग परीक्षण
│   └── Python测试/   # Python उन्नत ज्ञान परीक्षण
├── .gitignore
├── LICENSE               # Apache License 2.0
└── README*.md            # बहुभाषी README फ़ाइलें
```

## मुख्य विशेषताएँ

- **बहु-प्रारूप तुलना** — एक ही सामग्री 8 प्रारूपों में
- **बैच ऑटोमेशन** — प्रॉम्प्ट × प्रश्न × मॉडल का कार्टेशियन उत्पाद
- **बहु-मॉडल समानांतर** — क्षैतिज तुलना के लिए कई AI मॉडल
- **रीयल-टाइम SSE स्ट्रीमिंग**
- **बहु-दौर परीक्षण** — प्रति प्रश्न दोहराने योग्य
- **समकालिकता नियंत्रण**
- **वृद्धिशील सहेजना**
- **संग्रह स्नैपशॉट**

## त्वरित प्रारंभ

```bash
pip install -r APPs/requirements.txt
cd APPs
python app.py
```

ब्राउज़र खोलें: http://localhost:5000

शुरू करने के बाद, वेब UI के ऊपरी दाएं कोने में "सेटिंग्स" पर क्लिक करके API पता, मॉडल और पैरामीटर कॉन्फ़िगर करें।

## महत्वपूर्ण सूचना

**इस परियोजना में सभी परीक्षण डेटा सेट AI-जनित काल्पनिक डेटा हैं, वास्तविक डेटा नहीं। किसी भी वास्तविक इकाई, संगठन या परिदृश्य से समानता पूरी तरह से आकस्मिक है।** ये डेटा केवल संरचित प्रारूपों को समझने और पार्स करने की AI मॉडल की क्षमता का मूल्यांकन करने के लिए उपयोग किए जाते हैं।
