# FormTest - AI संरचित प्रारूप विश्लेषण क्षमता परीक्षण ढाँचा

> **संलग्न परीक्षण सेट सभी AI काल्पनिक डेटा हैं, वास्तविक डेटा नहीं। यदि कोई समानता पाई जाए, तो वह पूरी तरह से संयोगवश होगी।**
>
> **इस परियोजना को पर्याप्त प्रोग्रामेटिक निर्माण और परीक्षण योजना से नहीं गुज़रा है। कोड संरचना और परीक्षण कवरेज अभी पूर्ण नहीं हैं। यह केवल संदर्भ और सीखने के उद्देश्यों के लिए प्रदान किया गया है।**

एक स्वचालित परीक्षण ढाँचा जो बड़ी भाषा मॉडलों (LLM) की संरचित डेटा प्रारूपों को समझने और विश्लेषण करने की क्षमता का मूल्यांकन करता है। पूर्वनिर्धारित परीक्षण मामलों के माध्यम से, यह स्वचालित रूप से AI API को कॉल करता है और लौटाए गए परिणामों की अपेक्षित उत्तरों से तुलना करता है, जिससे मॉडल की प्रारूप समझने की क्षमता का मात्रात्मक मूल्यांकन होता है।

## त्वरित आरंभ

### 1. निर्भरताएँ स्थापित करें

```bash
pip install -r APPs/requirements.txt
```

### 2. प्रारंभ करें

```bash
cd APPs
python app.py
# या run.bat पर डबल-क्लिक करें
```

ब्राउज़र में खोलें [http://localhost:5000](http://localhost:5000)

### 3. कॉन्फ़िगरेशन

प्रारंभ करने के बाद वेब पेज के ऊपरी दाएँ कोने में **सेटिंग** बटन पर क्लिक करें और API पता, मॉडल, पैरामीटर आदि कॉन्फ़िगर करें। `APPs/config.example.json` देखकर भी कॉन्फ़िगरेशन फ़ाइल बनाई जा सकती है।

मुख्य कॉन्फ़िगरेशन आइटम:
- `base_url` — API पता (स्वचालित रूप से `/v1` जोड़ने का समर्थन)
- `model` — डिफ़ॉल्ट मॉडल नाम
- `model_thinking_config` — मॉडल के अनुसार थिंकिंग/रिज़निंग मोड कॉन्फ़िगरेशन
- `streaming` — SSE स्ट्रीमिंग स्विच
- `concurrency` — समवर्ती थ्रेड्स की संख्या
- `disabled_params` — फ्रंटएंड में छिपे/अक्षम पैरामीटर

### 4. परीक्षण चलाएँ

1. **कैनवास** पर नोड एडिटर के माध्यम से संयोजन बनाएँ: प्रॉम्प्ट × प्रश्न × मॉडल
2. **परीक्षण प्रारंभ करें** पर क्लिक करके स्ट्रीमिंग परिणाम रीयल-टाइम में देखें
3. परीक्षण पूरा होने के बाद **परिणाम इतिहास** में देखें/फ़िल्टर करें

## परीक्षण सेट

### संरचना

प्रत्येक परीक्षण सेट `.test-set-part` मार्कर फ़ाइलों के माध्यम से उपनिर्देशिकाओं की भूमिका पहचानता है। निर्देशिका नाम मनमाना हो सकता है; सिस्टम मार्कर फ़ाइल सामग्री के माध्यम से भूमिका पहचानता है:

```

├── <प्रश्न निर्देशिका>/            # .test-set-part → "questions" रखती है
│   ├── .test-set-part
│   ├── 基础问题.json                # 10 प्रश्न
│   └── 进阶问题.json                # 10 प्रश्न (कुछ सेटों में केवल बुनियादी प्रश्न)
├── <प्रॉम्प्ट निर्देशिका>/          # .test-set-part → "prompts" रखती है
│   ├── .test-set-part
│   ├── <नाम>原版.json               # सादा पाठ कथात्मक प्रारूप
│   ├── <नाम>列表.json               # क्रमांकित सूची प्रारूप
│   ├── <नाम>JSON.json               # JSON संरचित प्रारूप
│   ├── <नाम>YAML.json               # YAML प्रारूप
│   ├── <नाम>XML.json                # XML प्रारूप
│   ├── <नाम>Markdown.json           # Markdown तालिका प्रारूप
│   ├── <नाम>MarkdownKV.json         # Markdown कुंजी-मूल्य जोड़ा प्रारूप
│   └── <नाम>DSL.json                # कस्टम DSL प्रारूप
```

## मुख्य विशेषताएँ

- **दृश्य कैनवास एडिटर** — SVG नोड कैनवास, ड्रैग-एंड-ड्रॉप द्वारा प्रॉम्प्ट × प्रश्न × मॉडल का संयोजन, कनेक्शन लाइन ड्राइंग
- **पूर्ववत/पुनः करें** — पूर्ण इतिहास प्रणाली, Ctrl+Z / Ctrl+Shift+Z समर्थन
- **बहु-प्रारूप तुलनात्मक परीक्षण** — एक ही सामग्री 8 प्रारूपों में प्रस्तुत, प्रत्येक प्रारूप के लिए मॉडल की समझ में अंतर का मूल्यांकन
- **बैच स्वचालित परीक्षण** — प्रॉम्प्ट × प्रश्न × मॉडल का कार्टेशियन गुणनफल संयोजन, स्वचालित समवर्ती निष्पादन
- **बहु-मॉडल प्रबंधन** — मॉडल पॉपअप प्रबंधन, अतिरिक्त मॉडल जोड़ने/हटाने/क्रमबद्ध करने का समर्थन
- **रिज़निंग कॉन्फ़िगरेशन** — मॉडल के अनुसार स्वतंत्र रूप से thinking/reasoning_effort पैरामीटर कॉन्फ़िगर करें
- **पैरामीटर अक्षम टॉगल** — प्रत्येक पैरामीटर को dot-toggle के माध्यम से स्वतंत्र रूप से सक्षम/अक्षम करें
- **स्ट्रीमिंग रीयल-टाइम आउटपुट** — SSE-आधारित स्ट्रीमिंग परिणाम पुश, परीक्षण प्रगति रीयल-टाइम में दृश्य
- **परिणाम इतिहास देखें** — स्थिति/मॉडल/टेक्स्ट द्वारा ऐतिहासिक परिणाम खोज/फ़िल्टर करें
- **संग्रह/पुनर्स्थापना** — परीक्षण कॉन्फ़िगरेशन स्नैपशॉट सहेजें/लोड करें (कैनवास स्थिति + मॉडल रिज़निंग कॉन्फ़िगरेशन सहित)
- **_notFound मॉडल जाँच** — कैनवास स्वचालित रूप से अनुपलब्ध मॉडल का पता लगाता है और ⚠ चेतावनी दिखाता है
- **स्वचालित /v1 पूर्ति** — टॉगल स्विच, API पते के बाद स्वचालित रूप से `/v1` जोड़ें
- **गहरा/हल्का थीम** — थीम स्विचिंग के लिए पूर्ण CSS वेरिएबल सिस्टम
- **Anthropic API समर्थन** — Anthropic संदेश प्रारूप + समर्पित SSE रिज़निंग पार्सिंग समर्थन
- **बहु-दौर परीक्षण** — एक प्रश्न को कई बार दोहराया जा सकता है, उत्तर स्थिरता मापें
- **समवर्ती नियंत्रण** — कॉन्फ़िगरेबल समवर्ती थ्रेड संख्या और पुनः प्रयास रणनीति
- **वृद्धिशील सहेजना** — परीक्षण के दौरान समय-समय पर वृद्धिशील रूप से परिणाम सहेजें, आकस्मिक हानि से बचाएँ
- **पथ सुरक्षा सत्यापन** — पथ ट्रैवर्सल हमलों से सुरक्षा, Windows आरक्षित नाम जाँच, फ़ाइल नाम श्वेतसूची

## API इंटरफ़ेस

| एंडपॉइंट | विधि | विवरण |
|------|------|------|
| `/` | GET | फ्रंटएंड SPA प्रदान करता है |
| `/api/v1/config` | GET/POST | कॉन्फ़िगरेशन पढ़ना/सहेजना |
| `/api/v1/models` | GET/POST | उपलब्ध मॉडल सूची प्राप्त करना/सहेजना |
| `/api/v1/test-set/scan` | GET | परीक्षण सेट स्कैन करना |
| `/api/v1/test-set/prompts` | GET | परीक्षण सेट सिस्टम प्रॉम्प्ट प्राप्त करना |
| `/api/v1/test-set/questions` | GET | परीक्षण सेट प्रश्न प्राप्त करना |
| `/api/v1/test-set/results` | GET | ऐतिहासिक परीक्षण परिणाम प्राप्त करना |
| `/api/v1/test-job/hub` | POST | एकीकृत कार्य शेड्यूलिंग (action: start/status/stop) |
| `/api/v1/test-job/stream/<job_id>` | GET | SSE स्ट्रीमिंग रीयल-टाइम परिणाम पुश |
| `/api/v1/canvas-state` | GET/POST | कैनवास स्थिति सहेजना/पढ़ना |
| `/api/v1/archives` | GET/POST/DELETE | संग्रह प्रबंधन |
| `/api/v1/tags` | GET | सभी टैग प्राप्त करना |

त्रुटि प्रतिक्रियाएँ: `404` → `{"error": "Not found"}`, `500` → `{"error": "服务器内部错误"}`

| कौशल | विवरण |
|------|------|
| `new-test-set` | AI को परीक्षण सेट ढाँचा (निर्देशिका + मार्कर फ़ाइलें) बनाने में मार्गदर्शन करता है, स्वचालित क्रमांकन के साथ संघर्ष से बचाता है |
| `qa-extract` | AI को स्रोत फ़ाइलों से प्रश्न-उत्तर जोड़े निकालने में मार्गदर्शन करता है, आउटपुट प्रारूप FormTest परीक्षण सेट संगत JSON में |

## तकनीकी स्टैक

- **बैकएंड**: Python Flask + Flask-CORS
- **फ्रंटएंड**: नेटिव HTML / CSS (कस्टम वेरिएबल सिस्टम, गहरा/हल्का थीम) / JavaScript
- **AI कॉल**: `requests` लाइब्रेरी (SSE स्ट्रीमिंग और सामान्य JSON दोनों मोड, OpenAI / Anthropic API संगत)
- **समवर्ती**: `ThreadPoolExecutor` थ्रेड पूल + एक्सपोनेंशियल बैकऑफ़ रीट्राइ
- **आउटपुट**: Server-Sent Events (`text/event-stream`)
