# Фреймворк тестирования AI-моделей

> **警告 Warning**: 尚未完成正在优化前端随后重构后端及文件结构

Автоматизированный фреймворк для оценки способности больших языковых моделей (LLM) понимать и анализировать структурированные форматы данных.

## Обзор

Этот проект предназначен для оценки и тестирования способности AI-моделей понимать и анализировать файлы различных структурированных форматов данных. Через предварительно заданные тестовые случаи он автоматически вызывает AI API и сравнивает возвращенные результаты с ожидаемыми ответами, количественно оценивая производительность модели в понимании форматов.

## Поддерживаемые форматы

- XML
- JSON
- YAML
- Markdown (включая таблицы, пары ключ-значение)
- DSL (предметно-ориентированный язык)
- Простые текстовые списки

## Основные функции

1. **Мультиформатное тестирование**: Тестирование возможностей парсинга нескольких форматов данных одновременно
2. **Пакетное тестирование**: Выполнение тестовых случаев пакетами с потоковым выводом
3. **Поддержка нескольких моделей**: Настройка нескольких AI-моделей для сравнительного тестирования
4. **Кэширование ответов**: Избегание повторных вызовов API для ускорения итеративного тестирования
5. **Пользовательский системный промпт**: Настройка тестовых ассоциаций через bindings.json
6. **Контроль параллелизма**: Настраиваемое количество параллельных запросов и повторных попыток

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r 测试软件/requirements.txt
```

### 2. Запуск службы

```bash
cd 测试软件
python app.py
# или двойной щелчок по run.bat
```

### 3. Доступ к интерфейсу

Откройте браузер по адресу http://localhost:5000

### 4. Настройка и запуск

1. Настройте адрес API и параметры модели в разделе настроек
2. Выберите файлы форматов и группы тестовых вопросов для тестирования
3. Нажмите "Начать тестирование"
4. Просматривайте поток результатов в реальном времени и итоговые оценки

## Конфигурация

| Параметр | Описание | Значение по умолчанию |
|------|------|--------|
| base_url | Адрес API | http://192.168.1.45:1919/v1 |
| model | Название модели | qwen3.5-0.8b |
| temperature | Температура | 0.7 |
| concurrency | Параллельность | 1 |
| test_count | Тестов на вопрос | 1 |
| max_retries | Макс. повторных попыток | 3 |

## API эндпоинты

| Эндпоинт | Метод | Описание |
|------|------|------|
| /api/v1/config | GET/POST | Управление конфигурацией |
| /api/v1/models | GET | Получить доступные модели |
| /api/v1/ui-config | GET | Получить конфигурацию интерфейса |
| /api/v1/question-groups | GET | Получить группы вопросов |
| /api/v1/bindings | GET/POST | Настройка привязок |
| /api/v1/run-tests | POST | Выполнить тесты (потоковое SSE) |
| /api/v1/results | GET | Получить все результаты тестов |
| /api/v1/answer-cache | GET | Получить кэш ответов |

## Важное уведомление

### Заявление о тестовом наборе данных

**Весь контент в тестовом наборе данных этого проекта представляет собой сгенерированные AI примеры, а не реальные данные случаев.**

Тестовый набор данных включает:
- Примеры информации об обучающих видео
- Примеры журналов операций
- Примеры информации о предприятиях
- Примеры файлов в различных форматах (XML, JSON, YAML, Markdown, DSL)

Эти данные используются исключительно для тестирования способностей AI-моделей понимать и анализировать структурированные форматы и не представляют никаких реальных бизнес-сценариев.

## Технологический стек

- **Бэкенд**: Python Flask + Flask-CORS
- **Фронтенд**: Vanilla HTML + CSS + JavaScript
- **API вызовы**: requests (потоковое SSE)
- **Выполнение тестов**: Параллелизм ThreadPoolExecutor
