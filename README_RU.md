# FormTest - Фреймворк оценки парсинга структурированных форматов ИИ

> **Все тестовые наборы данных являются вымышленными данными, созданными ИИ, а не реальными данными. Любое совпадение с реальными объектами является случайным.**
>
> **Этот проект не имеет достаточного планирования построения программы и тестирования. Структура кода и покрытие тестами неполны. Только для ознакомительных и учебных целей.**

Автоматизированный фреймворк для оценки способности больших языковых моделей (LLM) понимать и анализировать структурированные форматы данных.

## Структура проекта

```
FormTest/
├── APPs/              # Основное приложение (бэкенд Flask + фронтенд HTML)
│   ├── app.py            # Точка входа Flask, REST API + SSE
│   ├── config.json       # Конфигурация выполнения
│   ├── requirements.txt  # Зависимости Python
│   ├── run.bat           # Скрипт быстрого запуска
│   ├── static/           # Файлы фронтенда
│   └── data/             # Данные выполнения
├── Benches/               # Тестовые наборы данных (сгенерированы ИИ, не реальные)
│   ├── 教学视频测试/     # Тест обучающего видео
│   ├── 企业信息测试/     # Тест корпоративной информации
│   ├── 运行日志测试/     # Тест системных журналов
│   └── Python进阶测试/   # Тест продвинутого Python
├── .gitignore
├── LICENSE               # Apache License 2.0
└── README*.md            # Многоязычные README файлы
```

## Основные функции

- **Мультиформатное сравнение** — Один контент в 8 форматах
- **Пакетная автоматизация** — Декартово произведение промптов × вопросов × моделей
- **Многомодельный параллелизм** — Горизонтальное сравнение моделей ИИ
- **Потоковая передача SSE в реальном времени**
- **Многократное тестирование** — Повторяемые тесты для каждого вопроса
- **Контроль параллелизма**
- **Инкрементальное сохранение**
- **Архивные снимки**

## Быстрый старт

```bash
pip install -r APPs/requirements.txt
cd 测试软件
python app.py
```

Открыть браузер: http://localhost:5000

После запуска нажмите «Настройки» в правом верхнем углу веб-интерфейса, чтобы настроить API-адрес, модель и параметры.
