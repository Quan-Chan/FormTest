# AI Model Testing Framework

一个用于测试大语言模型（LLM）对结构化数据格式解析能力的自动化测试框架。

## 项目概述

本项目用于评估和测试AI模型对各种数据格式文件的理解与解析能力。通过预设的测试用例，自动调用AI API并比对返回结果与预期答案，从而量化模型的格式理解性能。

## 项目结构

```
草稿A/
├── 测试软件/           # 主程序（Flask后端 + HTML前端）
├── 测试软件2/         # 配置变体（不同模型/参数）
├── 测试软件3/
├── 测试软件4/
├── 测试集/           # 测试数据集（非真实案例，AI合成）
│   ├── 被测试文件/    # 各种格式的示例文件
│   │   ├── XML/
│   │   ├── JSON/
│   │   ├── YAML/
│   │   ├── Markdown/
│   │   ├── DSL/
│   │   └── 列表示例/
│   ├── 教学视频测试问题/
│   ├── 运行日志测试问题/
│   ├── 企业信息测试问题/
│   └── UI.json       # 测试界面配置
├── 备份/             # 历史格式备份
├── 更新日志/         # Bug修复记录
└── 任务说明/         # 开发任务文档
```

## 支持的格式

- XML
- JSON
- YAML
- Markdown（含表格、KV键值对）
- DSL（领域特定语言）
- 纯文本列表

## 核心功能

1. **多格式测试**：同时测试多种数据格式的解析能力
2. **批量测试**：支持批量执行测试用例，流式输出结果
3. **多模型支持**：可配置多个AI模型进行对比测试
4. **答案缓存**：避免重复调用API，加速迭代测试
5. **自定义System Prompt**：支持通过bindings.json配置测试关联
6. **并发控制**：可配置并发数和重试次数

## 快速开始

### 1. 安装依赖

```bash
pip install -r 测试软件/requirements.txt
```

### 2. 启动服务

```bash
cd 测试软件
python app.py
# 或双击 run.bat
```

### 3. 访问界面

浏览器打开 http://localhost:5000

### 4. 配置与运行

1. 在设置中配置API地址、模型参数
2. 选择要测试的格式文件和测试问题组
3. 点击"开始测试"
4. 查看实时结果流和最终得分

## 配置说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| base_url | API地址 | http://192.168.1.45:1919/v1 |
| model | 模型名称 | qwen3.5-0.8b |
| temperature | 温度参数 | 0.7 |
| concurrency | 并发数 | 1 |
| test_count | 单题测试次数 | 1 |
| max_retries | 最大重试次数 | 3 |

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/v1/config | GET/POST | 配置管理 |
| /api/v1/models | GET | 获取可用模型列表 |
| /api/v1/ui-config | GET | 获取测试界面配置 |
| /api/v1/question-groups | GET | 获取问题组列表 |
| /api/v1/bindings | GET/POST | 绑定配置管理 |
| /api/v1/run-tests | POST | 执行测试（SSE流式输出） |
| /api/v1/results | GET | 获取所有测试结果 |
| /api/v1/answer-cache | GET | 获取答案缓存 |

## 重要说明

### 测试数据集声明

**本项目测试集中的所有内容均为AI合成生成的示例，非真实案例数据。**

测试集包括：
- 教学视频信息示例
- 运行日志示例
- 企业信息示例
- 各种格式（XML、JSON、YAML、Markdown、DSL）的示例文件

这些数据仅用于测试AI模型对结构化格式的理解和解析能力，不代表任何真实业务场景。

## 技术栈

- **后端**：Python Flask + Flask-CORS
- **前端**：原生HTML + CSS + JavaScript
- **API调用**：requests（流式SSE）
- **测试执行**：ThreadPoolExecutor并发
