# AIモデルテストフレームワーク

大規模言語モデル（LLM）の構造化データフォーマット解析能力を評価するための自動化テストフレームワーク。

## 概要

このプロジェクトは、AIモデルが各種構造化データフォーマットファイルを理解和析する能力を評価・テストするために設計されています。プリセットされたテストケースを通じて、AI APIを自動的に呼び出し、返された結果を期待される回答と比較することで、モデルのフォーマット理解性能を定量的に測定します。

## プロジェクト構造

```
草稿A/
├── テストソフトウェア/    # メインアプリケーション（Flaskバックエンド + HTMLフロントエンド）
├── テストソフトウェア2/  # 設定バリエーション（異なるモデル/パラメータ）
├── テストソフトウェア3/
├── テストソフトウェア4/
├── テスト集/          # テストデータセット（非リアルタイムケース、AI生成）
│   ├── 被テストファイル/  # 各種フォーマットのサンプルファイル
│   │   ├── XML/
│   │   ├── JSON/
│   │   ├── YAML/
│   │   ├── Markdown/
│   │   ├── DSL/
│   │   └── 列表示例/
│   ├── 教学動画テスト問題/
│   ├── 実行ログテスト問題/
│   ├── 企業情報テスト問題/
│   └── UI.json       # テストインターフェース設定
├── バックアップ/          # historicalフォーマットバックアップ
├── 更新ログ/          # バグ修正ログ
└── タスク説明/        # 開発タスク文書
```

## 対応フォーマット

- XML
- JSON
- YAML
- Markdown（テーブル、KVキー、バリューペアを含む）
- DSL（ドメイン固有言語）
- プレーンテキストリスト

## コア機能

1. **マルチフォーマットテスト**: 複数のデータフォーマットのパース能力を同時にテスト
2. **バッチテスト**: ストリーミング出力でテストケースを一括実行
3. **マルチモデルサポート**: 複数のAIモデルを比較テスト用に設定
4. **アンサーキャッシング**: 反復的なAPI呼び出しを回避し、反復テストを加速
5. **カスタムシステムプロンプト**: bindings.jsonでテスト関連を設定
6. **并发制御**: 設定可能な并发数とリトライ回数

## クイックスタート

### 1. 依存関係のインストール

```bash
pip install -r テストソフトウェア/requirements.txt
```

### 2. サービスの起動

```bash
cd テストソフトウェア
python app.py
# またはrun.batをダブルクリック
```

### 3. インターフェースへのアクセス

ブラウザで http://localhost:5000 を開く

### 4. 設定と実行

1. 設定でAPIアドレスとモデルパラメータを設定
2. テストするフォーマットファイルとテスト問題グループを選択
3. 「テスト開始」をクリック
4. リアルタイム結果ストリームと最終スコアを表示

## 設定

| パラメータ | 説明 | デフォルト |
|------|------|--------|
| base_url | APIアドレス | http://192.168.1.45:1919/v1 |
| model | モデル名 | qwen3.5-0.8b |
| temperature | 温度 | 0.7 |
| concurrency | 并発数 | 1 |
| test_count | 1題あたりのテスト回数 | 1 |
| max_retries | 最大リトライ回数 | 3 |

## APIエンドポイント

| エンドポイント | メソッド | 説明 |
|------|------|------|
| /api/v1/config | GET/POST | 設定管理 |
| /api/v1/models | GET | 利用可能モデル一覧取得 |
| /api/v1/ui-config | GET | テストインターフェース設定取得 |
| /api/v1/question-groups | GET | 問題グループ一覧取得 |
| /api/v1/bindings | GET/POST | バインディング設定 |
| /api/v1/run-tests | POST | テスト実行（SSEストリーミング） |
| /api/v1/results | GET | 全テスト結果取得 |
| /api/v1/answer-cache | GET | アンサーキャッシュ取得 |

## 重要なお知らせ

### テストデータセットに関する声明

**このプロジェクトのテストデータセット内のすべてのコンテンツはAI生成の例であり、実際のケースデータではありません。**

テストデータセットには以下が含まれます：
- チュートリアル動画情報の例
- 実行ログの例
- 企業情報の例
- 各種フォーマット（XML、JSON、YAML、Markdown、DSL）のサンプルファイル

これらのデータは、構造化フォーマットのAIモデルの理解和析能力をテストするためだけに使用されており、実際のビジネスシナリオを表すものではありません。

## テクノロジスタック

- **バックエンド**: Python Flask + Flask-CORS
- **フロントエンド**: バナILLA HTML + CSS + JavaScript
- **API呼び出し**: requests（ストリーミングSSE）
- **テスト実行**: ThreadPoolExecutor并发
