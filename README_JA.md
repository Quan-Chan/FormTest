# FormTest - AI構造化フォーマット解析評価フレームワーク

> **テストデータセットはすべて AI が生成した架空のデータであり、実在のデータではありません。万一、実在の人物・団体などと一致した場合は、まったくの偶然です。**
>
> **このプロジェクトは、プログラム構築とテストの十分な計画がなされていません。コード構造とテストカバレッジは不完全です。参考および学習目的のみでご利用ください。**

大規模言語モデル（LLM）の構造化データフォーマット解析能力を評価するための自動化テストフレームワーク。

## プロジェクト構造

```
FormTest/
├── 测试软件/              # メインアプリケーション（Flaskバックエンド + HTMLフロントエンド）
│   ├── app.py            # Flaskエントリポイント、REST API + SSEストリーミング
│   ├── config.json       # 実行時設定
│   ├── requirements.txt  # Python依存関係
│   ├── run.bat           # クイックスタートスクリプト
│   ├── static/           # フロントエンドファイル
│   └── data/             # 実行時データ
├── 测试集/               # テストデータセット（AI生成、実データではありません）
│   ├── 教学视频测试/     # 教学ビデオコンテンツテスト
│   ├── 企业信息测试/     # 企業情報テスト
│   ├── 运行日志测试/     # システム運用ログテスト
│   └── Python进阶测试/   # Python発展的知識テスト
├── .gitignore
├── LICENSE               # Apache License 2.0
└── README*.md            # 多言語READMEファイル
```

## 主な機能

- **マルチフォーマット比較** — 同一コンテンツを8形式で提示
- **バッチ自動化** — プロンプト×質問×モデルの直積
- **マルチモデル並列** — 複数AIモデルの水平比較
- **リアルタイムSSEストリーミング**
- **複数回テスト** — 質問ごとに繰り返し実行可能
- **同時実行制御**
- **インクリメンタル保存**
- **アーカイブスナップショット**

## クイックスタート

```bash
pip install -r 测试软件/requirements.txt
cd 测试软件
python app.py
```

ブラウザで開く: http://localhost:5000

## 重要なお知らせ

**このプロジェクトのテストデータセットはすべて AI が生成した架空のデータであり、実在のデータではありません。万一、実在の人物・団体・シナリオなどと一致した場合は、まったくの偶然です。** これらのデータは、構造化フォーマットに対するAIモデルの理解・解析能力を評価するためだけに使用されます。
