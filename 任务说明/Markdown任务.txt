## 背景

### 现状问题

1. **Root.json 和 UI.json 重复定义映射** - 手动维护繁琐
2. **被测试文件 ↔ 测试问题 硬绑定** - 在UI.json中写死
3. **bindings功能前端可用但后端未使用** - 断头路
4. **系统提示使用硬编码模板** - 无法使用自定义内容

### 示例2: get_ui_config() 自动扫描

```python
def get_ui_config():
    test_set_dir = get_test_set_dir()
    formatGroups = []

    # 自动扫描被测试文件
    src_dir = os.path.join(test_set_dir, "被测试文件")
    for category in os.listdir(src_dir):
        category_path = os.path.join(src_dir, category)
        if os.path.isdir(category_path):
            files = []
            for f in os.listdir(category_path):
                if f.endswith('.txt'):
                    files.append({
                        "source": f"测试集/被测试文件/{category}/{f}",
                        "testQuestion": f"测试集/questions/{category}"
                    })
            formatGroups.append({"name": category, "files": files})

    return {"formatGroups": formatGroups}
```
